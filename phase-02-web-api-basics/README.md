## Overview

Phase 02 focuses on building ASP.NET Core Web APIs using REST, routing, DTOs, services, validation, Swagger, and Postman.

## Tasks

* **Task 00 - API Workspace Setup**
  Created and configured the ASP.NET Core Web API project with Swagger.

* **Task 01 - REST & Routing Drill Pack**
  Practiced HTTP methods, routing, query parameters, request bodies, status codes, and response shapes.

* **Task 02 - Student Management API**
  Built a Student Management API with CRUD operations, validation, search, filtering, pagination, and statistics.

* **Task 03 - Products & Categories API**
  Built a Products and Categories API with CRUD operations, relationships, filtering, search, and stock reports.

* **Task 04 - Book Store API Mini-Project**
  Built a Book Store API for books, authors, and categories with validation, search, filtering, pagination, and reports.

* **Task 05 - Swagger & Postman Evidence Pack**
  Documented and tested the APIs using Swagger and Postman, including success and error cases.

* **Task 06 - API Standards & Refactor Pack**
  Refactored bad API code into a cleaner structure using DTOs, services, validation, RESTful routes, and proper status codes.

* **Task 07 - Interview Answers & API Explanation Pack**
  Prepared short explanations for REST, HTTP, controllers, DTOs, services, DI, validation, testing, and API architecture.
