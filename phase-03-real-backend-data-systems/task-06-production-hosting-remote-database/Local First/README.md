# Training Center API

ASP.NET Core Web API for managing a Training Center system.

### Technologies

* ASP.NET Core Web API
* Entity Framework Core
* SQL Server
* Swagger

### Deployment

* Created and configured the SQL Server database.
* Published the API to a live website.
* Live API: http://trainngcenter.runasp.net/swagger/index.html

### Main Features

* Students
* Instructors
* Tracks
* Enrollments
* Payments
* Reports
* Filtering & Pagination
