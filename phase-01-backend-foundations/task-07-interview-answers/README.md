# Task 07 - Interview Answers & Explanation Pack

## Task Description

This task focuses on explaining the concepts and techniques learned during Phase 01.

The goal is to understand the concepts, not just write code. The answers are written in my own words and are related to the tasks I completed during this phase.

## Topics Covered

The interview questions cover the following topics:

* Object-Oriented Programming
* Classes and Objects
* Encapsulation
* Fields and Properties
* Constructors
* Service Classes
* Code Organization
* Collections
* List and Array
* Dictionary
* LINQ
* Where, Select, GroupBy
* Skip and Take
* SQL and Database Concepts
* Primary Keys and Foreign Keys
* Relationships
* JOIN
* Tables and Entities
* GitHub
* README Documentation
* Git Commits
* Professional Project Delivery

## Answer Format

Each question contains:

* An answer written in Arabic in my own words.
* An English translation of the answer.
* Examples where they help explain the concept.

The answers are kept short and focused so they can also be used as preparation for technical interviews.

## Relation to Phase 01 Tasks

The answers are connected to the practical tasks completed during Phase 01.

For example:

* OOP concepts are related to the earlier C# and Bank Account tasks.
* Service classes and code organization are related to the refactoring task.
* LINQ concepts are related to the LINQ task.
* Primary keys, foreign keys, relationships, and JOIN are related to the Library Management System in Task 06.
* GitHub, README files, and commits are related to the project delivery requirements.

## Goal

The main goal of this task is to be able to explain the concepts I used during the previous tasks clearly and confidently, rather than only being able to implement them in code.
